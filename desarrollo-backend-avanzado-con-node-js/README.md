# BookShop API - Backend Avanzado

API REST para una plataforma de compraventa de libros de segunda mano.

Los usuarios pueden registrarse, iniciar sesión, publicar libros, editar sus publicaciones, consultar el catálogo y comprar libros de otros usuarios.

## Tecnologías

- Node.js
- Express
- TypeScript
- PostgreSQL
- Prisma ORM
- Docker y Docker Compose
- JWT
- bcrypt
- Nodemailer
- MailDev
- node-cron
- Jest
- Supertest

## Requisitos

- Node.js 18 o superior
- npm
- Docker Desktop
- Docker Compose

## Instalación

```bash
npm install
```
